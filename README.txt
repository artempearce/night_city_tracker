NIGHT CITY // TRACKER — PWA-пакет
===================================

В архиве:
  index.html              — сам трекер
  manifest.json           — описание приложения для установки
  sw.js                   — service worker (офлайн-режим)
  icon-192.png / icon-512.png / icon-maskable-512.png — иконки

ВАЖНО про установку как настоящего PWA (с иконкой на экране,
офлайн-режимом и т.д.):

Чтобы браузер предложил "Установить приложение" и включил
офлайн-кэширование через service worker, эти файлы нужно открывать
не как обычный локальный файл (file://), а с настоящего хостинга
по https (или localhost). Это ограничение браузеров, а не трекера.

Проще всего — бесплатный статический хостинг:
  1. GitHub Pages: создать репозиторий, загрузить все файлы из
     архива в корень, включить Pages в настройках репозитория.
  2. Netlify Drop (app.netlify.com/drop): просто перетащить папку
     с файлами — сайт появится за несколько секунд.
  3. Cloudflare Pages, Vercel — аналогично.

После этого открой сайт в браузере телефона → появится баннер/пункт
меню "Добавить на экран Домой" или "Установить" — так у тебя будет
отдельная иконка и трекер будет открываться как настоящее приложение.

Если просто открыть index.html локальным файлом — трекер тоже
полностью работает (progress сохраняется через localStorage браузера,
как и раньше), просто без иконки на рабочем столе и офлайн-кэша.

Перенос прогресса со старой версии: Настройки → Экспортировать
прогресс (в старом файле) → открой новую версию → Настройки →
Импортировать прогресс → выбери сохранённый JSON.
